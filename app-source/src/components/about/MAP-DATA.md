Country geometry is derived from Natural Earth 1:110m Admin 0 Countries (public domain).
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Projection: equirectangular, x=(longitude+180)*1000/360, y=(90-latitude)*1000/360.
Antarctica omitted for layout. Country pins indicate approximate country centers, not office addresses.
The regional detail view uses the same geometry and coordinates as the world view.
